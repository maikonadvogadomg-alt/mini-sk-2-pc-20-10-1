# Mini SK 2 para PC (.exe) — 20/10

É o **Mini SK 2** num programa do Windows. Instala **ao lado** do Mini SK que você já tem, sem substituir:
- nome próprio: **Mini SK 2** (ícone próprio na área de trabalho);
- pasta própria dos projetos: **Documentos\Mini-SK-2** (o Mini SK continua usando Documentos\Mini-SK);
- portas próprias (7690, 7691, 7692): dá para abrir os dois ao mesmo tempo.

Tem tudo do Mini SK para PC: **💻 Terminal do computador**, **📁 Pasta viva** (a árvore e a pasta sempre iguais), **📂 Abrir no Windows** e o **Ollama**.
E as novidades do Mini SK 2: abre **.tar / .tar.gz / .tgz**.

## Como gerar o .exe (uma vez)
1. Mande esta pasta para um repositório **novo** no GitHub (Mini SK → 🐙 GitHub). Ex.: `mini-sk-2-pc`.
2. GitHub → **Actions** → **Programa .exe para Windows (Mini SK 2)** → **Run workflow**.
3. Verde ✔: abra a execução → **Artifacts** → baixe **Mini-SK-2-Windows**. Vermelho ✖: mande print do passo vermelho.
4. No PC: dois cliques em **Mini-SK-2-Instalar.exe**. Se o Windows avisar: **Mais informações → Executar assim mesmo**.

## Para os comandos npm funcionarem
Instale o **Node.js LTS** no PC (nodejs.org), uma vez.

Se der erro, o motivo fica em **Documentos\Mini-SK-2\registro.txt**.
